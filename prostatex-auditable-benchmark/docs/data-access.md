# Data Access

The source MRI examinations and finding labels originate from the public PROSTATEx collection. Use the dataset citation in `manuscript/references.tex` to locate the authoritative collection record.

This repository does not redistribute raw DICOM images. The frozen download plan, selected study and series identifiers, finding coordinates, patient-level folds, and patch metadata are provided to support reconstruction from the authoritative source.

Before publishing any derived patch archive, confirm that redistribution is compatible with the current PROSTATEx and TCIA terms. Do not add credentials, local access tokens, private paths, or unrelated clinical data to this repository.
